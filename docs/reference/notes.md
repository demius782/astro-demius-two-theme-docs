# 开发日志

demigod 的开发重点是把第一屏体验做完整，同时保持文章内容和配置结构简单。

- [主题介绍：沉浸式博客的第一屏](../guide/introducing-demigod.html)：定位、视觉语言和核心交互。
- [短代码展示](../guide/shortcodes-showcase.html)：内容组件在主题中的实际写法。
- [归档、分类与搜索](../guide/archive-category-search.html)：内容组织和查找路径。

后续扩展优先考虑评论适配、图片灯箱、音乐播放器、生活数据和更多媒体组件；每项功能都应通过配置逐步启用，避免增加主题初始复杂度。
