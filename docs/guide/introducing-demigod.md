demigod 是一个以第一屏体验为核心的 Astro 博客主题。它不是传统的文章列表首页，而是把背景视频、中央阅读区、右侧文章卡片和底部推荐轮播放在同一个沉浸式场景里，让读者进入页面后立刻知道站点的气质和内容方向。

主题的视觉重点是电影感背景和克制的玻璃浮层。背景负责提供氛围，中央区域负责承载标题和正文，右侧卡片负责快速浏览文章，底部轮播负责展示推荐内容。几个区域各司其职，不互相抢状态，也不要求用户在多个页面之间频繁跳转。

demigod 适合个人博客、主题展示站、设计札记、开发日志和小型作品集。如果你希望首页不是简单的列表，而是一个有明显记忆点的阅读入口，它会比通用博客模板更贴合这类需求。
