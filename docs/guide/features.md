# 功能指南

## 沉浸式首页

背景负责氛围，中央区域负责标题和正文，右侧卡片负责快速浏览，底部轮播负责推荐文章。每个区域都有清晰职责，适合主题展示、开发日志和个人博客。

## 文章卡片与轮播

文章的 `featured: true` 会进入右侧精选卡片，`carousel: true` 会进入底部轮播。两者共用 `src/content/posts/`，不需要维护额外数组。

## 搜索与阅读体验

主题包含搜索弹窗、阅读进度、移动端导航和 Artalk 评论。交互组件按需加载，正文内容保持可读和可索引。

## 短代码

主题支持提示块、折叠、选项卡、链接卡片、媒体嵌入等内容组件，具体写法见[短代码示例](shortcodes-showcase.html)。
