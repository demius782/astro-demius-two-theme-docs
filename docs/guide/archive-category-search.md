demigod 的顶部菜单不会跳转路由。点击文章时，中央区域会切换为归档视图；点击分类时，中央区域会显示分类卡片；点击某个分类后，会进一步展示该分类下的文章列表。

这种设计保留了沉浸式首页的连续感。背景、右侧卡片和底部轮播不会因为导航切换而重置，读者始终停留在同一个视觉场景中，只是中央阅读区域发生变化。

搜索功能使用弹窗形式。打开搜索后，可以按标题、摘要、正文、分类和标签检索文章。点击搜索结果后，弹窗关闭，文章正文会直接显示在中央区域。

归档和分类并不是装饰模块，而是博客主题必须具备的内容组织能力。它们让读者可以从时间、主题和关键词三个方向找到文章，也让单页主题不至于只停留在展示效果上。
